# UGC Maker LP

`service.ugcmaker.jp` のマーケティング LP（静的 HTML / Vercel ホスティング）。

- 本体: `index.html`（単一ファイル。CSS / JS をインラインで内包）
- 素材: `lp-videos/`（動画・ロゴ・イラスト）
- 下層ページ: `terms/` `privacypolicy/`
- API: `api/notify.js`（問い合わせ通知）

ローカル確認:

```bash
python3 -m http.server 8765
# http://localhost:8765/        本番相当の表示
# http://localhost:8765/?local  ローカル限定要素も表示
```

デプロイ: `vercel --prod`（GitHub 自動デプロイは未設定。CLI から手動）。

# 🎨 Design System

`index.html` の `:root` に CSS 変数（トークン）として定義。**新規スタイルは必ずこのトークンを使う**こと。生の HEX / 任意のサイズを直書きしない。

## タイポグラフィ

### フォントファミリー
| トークン | フォント | 用途 |
|---------|---------|------|
| `--font-body` | Noto Sans JP | 和文すべて（本文・見出し） |
| `--font-display` | Nunito Sans | **数字・英字**（実績数値・ラベル等） |

- 運用ルール: **和文 = Noto Sans JP / 数字・英字 = Nunito Sans**
- ウェイトは **400 / 700 / 900** の3段に統一（中間の 500・600・800 は使わない）

### タイプスケール（8段）
| トークン | 値 | px | 用途 |
|---------|-----|----|----|
| `--fs-xs` | 0.75rem | 12 | キャプション・注記 |
| `--fs-sm` | 0.8125rem | 13 | 補助テキスト |
| `--fs-body` | 0.9375rem | 15 | 和文本文・カード説明 |
| `--fs-base` | 1rem | 16 | 標準本文 |
| `--fs-md` | 1.125rem | 18 | カード見出し |
| `--fs-lg` | 1.25rem | 20 | 小見出し |
| `--fs-xl` | 1.5rem | 24 | H3 |
| `--fs-2xl` | 2rem | 32 | 大見出し |

特殊サイズ（スケール外・意図的に大きい箇所のみ）:
- セクション見出し `.sec-title`: `clamp(1.75rem, 3vw, 2.5rem)`
- ヒーロー `.hero-h1`: 3.2rem / `.big` 4rem

### その他タイポ規則
- 行間: 和文本文 **1.7–1.8** / 見出し **1.5**
- 字間: 見出しは **0.02em**（和文が間延びしないように）

## イラスト / アイコン（Google フラットスタイル）

LP のアイコン・図版は **インライン SVG** で、以下の画風に統一する:

- **輪郭線なし**のフラットなベタ塗り
- 主色 `#4285F4`、アクセント `#FBBC04`、状態色 `#34A853` / `#EA4335`、白・淡青
- 淡い青の **ブロブ背景**（`#C3D6F9` / `#D2E3FC` / `#E8F0FE`）で奥行きを出す
- 浮遊する白チップ＋ソフトシャドウで「自動で要素が追加される」ニュアンスを表現

viewBox の慣例:
| 用途 | viewBox |
|------|---------|
| お悩みカードのアイコン | `0 0 240 180` |
| 機能カードのビジュアル | `0 0 320 200`（16:10） |
| ステップの丸アイコン | `0 0 200 200`（円バッジ） |

## レイアウト / コンポーネント

- セクション: `.sec`（padding `6.4vw 7vw`）> `.sec-inner`（`max-width:1280px` 中央寄せ）
- 見出し構造: `.sec-title`（H2）+ 必要なら `.sec-sub`
- スクロール表示アニメーション: 要素に `.anim` を付与（IntersectionObserver で `.visible` 付与）
- 環境出し分け: `data-local-only`（本番非表示・`?local` で表示）/ `.trust-hide-on-local`（ローカル非表示）

### 角丸（推奨スケール / 移行中）
`8px`（小=ボタン・チップ）/ `12px`（中=ビジュアル）/ `16px`（大=カード）/ `999px`（ピル）

### スペーシング（推奨スケール / 移行中）
8px 基準: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`px
